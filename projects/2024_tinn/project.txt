Tinn is a desktop application for specifying a project in the built environment. It holds the messy middle of specification work — materials, products, surfaces, dimensions — in a single file the user owns. It is offline-first, prints clean, and is built for the way architects, engineers, interior designers and builders actually plan a space: with deep attention to one room at a time, with paper and pen still on the desk, with file ownership that outlasts any subscription.

The project grew out of a frustration with existing tools. The software available for specifying a project — for architects, engineers and designers — was built for someone else: project managers, retailers, e-commerce teams. None of it respected the way the built environment is actually drawn up. Tinn is an attempt to write that tool from the ground up, by someone who has lived inside the problem.

My role spans concept, visual design, brand and the codebase itself. The application is a Tauri 2 / React desktop app with a Rust core and a local SQLite store, distributed as a signed installer for Windows and (soon) macOS. The visual language is restrained — quiet typography, thin black lines, sharp corners — informed by the catalogues and books I keep open on the studio shelf: Sirotov, Ecohaus, Branco Arquitetura.

Tinn is currently in early access, with new capabilities added each month.

Tinn é um aplicativo de desktop para especificar um projeto no ambiente construído. Ele guarda o meio bagunçado do trabalho de especificação — materiais, produtos, superfícies, dimensões — em um único arquivo que o usuário possui. Funciona offline, imprime de forma limpa, e é construído para a maneira como arquitetos, engenheiros, designers de interiores e construtores realmente planejam um espaço: com atenção profunda a um cômodo de cada vez, com papel e caneta ainda sobre a mesa, e com uma posse de arquivo que sobrevive a qualquer assinatura.

O projeto nasceu da frustração com as ferramentas existentes. Os softwares disponíveis para especificar um projeto — para arquitetos, engenheiros e designers — foram feitos para outra pessoa: gerentes de projeto, varejistas, equipes de e-commerce. Nenhum deles respeitava a forma como o ambiente construído realmente é desenhado. Tinn é uma tentativa de escrever essa ferramenta do zero, por alguém que viveu dentro do problema.

Minha função abrange o conceito, o design visual, a marca e o próprio código. A aplicação é um app de desktop Tauri 2 / React com um núcleo em Rust e uma base SQLite local, distribuída como um instalador assinado para Windows e (em breve) macOS. A linguagem visual é contida — tipografia silenciosa, linhas pretas finas, cantos nítidos — inspirada nos catálogos e livros que mantenho na estante do estúdio: Sirotov, Ecohaus, Branco Arquitetura.

Tinn está atualmente em acesso antecipado, com novas funcionalidades adicionadas a cada mês.
