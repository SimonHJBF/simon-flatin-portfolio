Tinn is a desktop app for specifying a project in the built environment. It holds the messy middle of the work in one place: materials, products, surfaces, dimensions. The user owns the file. It runs offline, prints clean, and is built around how architects, engineers, interior designers and builders actually plan a space. One room at a time. Paper and pen still on the desk. A file that outlasts any subscription.

I started Tinn because the existing tools were always built for someone else. The software you find when you go looking for a way to specify a project, even when it's marketed at architects, was really made for project managers, retailers, e-commerce teams. None of it respected the way a building is actually drawn up. So I started writing the tool I wished I had.

I do the concept, the visual design, the brand and the code. The visual language is restrained: quiet typography, thin black lines, sharp corners.

Tinn is in early access. New capabilities arrive each month.

Tinn é um aplicativo de desktop para especificar um projeto no ambiente construído. Ele guarda o meio bagunçado do trabalho num só lugar: materiais, produtos, superfícies, dimensões. O usuário é dono do arquivo. Funciona offline, imprime limpo, e foi feito em torno de como arquitetos, engenheiros, designers de interiores e construtores realmente planejam um espaço. Um cômodo de cada vez. Papel e caneta ainda sobre a mesa. Um arquivo que dura mais que qualquer assinatura.

Comecei o Tinn porque as ferramentas existentes sempre foram feitas para outra pessoa. O software que se encontra quando se procura uma forma de especificar um projeto, mesmo quando vendido a arquitetos, era na verdade feito para gerentes de projeto, varejistas, times de e-commerce. Nenhum deles respeitava o jeito como um edifício é realmente desenhado. Então comecei a escrever a ferramenta que eu queria ter.

Eu faço o conceito, o design visual, a marca e o código. A linguagem visual é contida: tipografia silenciosa, linhas pretas finas, cantos nítidos.

Tinn está em acesso antecipado. Novas funcionalidades chegam a cada mês.
