HOW TO USE THIS TEMPLATE
─────────────────────────
1. Duplicate this entire folder
2. Rename it:  YYYY_project-slug  (e.g. 2025_oslo-library)
   — The year prefix keeps folders sorted newest-first in Explorer/Finder
   — The slug becomes the URL: /projects/oslo-library/
3. Edit project.txt with your content
4. Add images to this folder:
   — cover.jpg          → hero image at the top of the project page
   — image-01.jpg, image-02.jpg, etc.  → gallery below
   (Supported: jpg, jpeg, png, webp, gif, avif)
5. Commit and push — Netlify rebuilds the site automatically
